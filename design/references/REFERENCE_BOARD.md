# Reference Board — Multi-Source Synthesis

| Source | Role in Process | Specific Elements Learned & Applied | Explicitly Rejected / Not Copied |
| :--- | :--- | :--- | :--- |
| **Kage** (`https://kage.design`) | Full-product composition & pane hierarchy | Asymmetric 3-pane workbench (`256px` rail / `1fr` primary conversation / collapsible `400px` inspector dock); strict `720px` reading measure in main thread; hairline `1px` architectural boundaries. | Fake macOS terminal window chrome, bento landing grids, decorative gradients, dark-purple AI styling. |
| **Refero Styles** (`https://styles.refero.design`) | Style system comparison & palette/spacing grammar | Compared 3 systems: (1) *Industrial Monochrome Terminal* (`1px` rules, stepped slate steps, zero shadow), (2) *Editorial Technical Docs* (restrained warm off-white ink `#ebe6da`, wide `1.55` line height), (3) *Hardware Patchbay* (sharp `2px` chamfers, brass `#d4a243` + frost `#5cc8ff` semantic accents). Merged into one proprietary **Mimir Basalt & Brass Runestone** grammar. | Raw third-party `DESIGN.md` dumps, neon cyberpunk bloom, soft `16–24px` capsule radii, drop-shadow elevation stacks. |
| **Minimal Gallery** (`https://minimal.gallery`) | Restraint, viewport budget, negative space | High signal-to-chrome ratio: collapse ancillary panels below `1120px`, move secondary nav/history to slide-over drawer at `<= 900px`, keep empty/welcome state focused strictly on 1 crest emblem + 1 real prompt action. | Fashion editorial giant hero fonts, decorative scroll-jacking, empty whitespace without working controls. |
| **Component Gallery** (`https://component.gallery`) | Accessible interaction & keyboard ARIA mechanics | WAI-ARIA Tablist (`role="tablist"`, `role="tab"`, `aria-selected`, Left/Right arrow navigation), Alert/Modal Dialog (`role="dialog"`, `aria-modal="true"`, Escape dismiss, initial focus + focus restore), native `<details>/<summary>` Disclosure, explicit separate button vs action controls (zero nested interactive controls), real `<input type="checkbox">` inside full-hit-target cards. | Default unstyled browser focus outlines without custom high-contrast focus ring, clicking row containers that hijack child buttons. |
| **Uiverse** (`https://uiverse.io`) | Micro-interaction CSS mechanics only | Tactile `1px` mechanical press translate (`active: translateY(1px)`), crisp checkbox tick state-transition (`border-color` + checkmark stroke draw / crisp fill swap), horizontal progress bar fill (`scaleX` transform) for approvals & model compiles. | Neon box-shadows, `backdrop-filter: blur(...)` liquid glass, rainbow animated borders, hover lift `translateY(-4px)` on static cards, spinning decorative rings. |
| **Tabler Icons** (`https://tabler.io/icons`) | Functional UI icons (`24x24`, consistent stroke) | Standardized `24x24` `viewBox="0 0 24 24"`, uniform `strokeWidth="1.75"`, `strokeLinecap="square"`, `strokeLinejoin="miter"` for sharp pixel-compatible architectural clarity (plus `+`, send arrow, command spotlight search, message bubble, anvil/tool, folder/attach, clock, box, shield, sliders, menu hamburger, X close). | Sparkle stars, gradient fills inside UI icons, mixed icon stroke weights, decorative icon spam next to non-interactive labels. |
| **Blush** (`https://blush.design`) | Evaluated & intentionally skipped | Evaluated; Mimir is a technical desktop & browser operations console where functional screenshots, code traces, and the single crisp proprietary carved Mimir crest outperform generic character illustrations. | Startup people illustrations, empty-state cartoon filler. |
| **Meshy** (`https://www.meshy.ai`) | Evaluated & intentionally skipped | Evaluated; WebGL GLB scenes add memory/LCP weight and risk failing headless/software Electron renderers without adding real functional value over live Playwright browser viewports. | Gratuitous 3D floating artifacts. |
