3-Step Local Onboarding

Up and running in under five minutes

Whether you already use Ollama or are starting fresh on Windows, Mimir stays local and tells you what is running at each step.

1. Install or Launch Local Runtime

Open the Windows Desktop installer build (Mimir Setup 1.0.3.exe) or run npm run dev:daemon in your local checkout.

2. Pair Browser Session Safely

Open /app.html. The app checks 127.0.0.1:4567, prints a 6-character pairing code in your local Mimir window or terminal, and exchanges it for a short-lived session token.

3. Connect Ollama & Run First Task

Mimir detects installed Ollama models automatically, or helps you pull a starter model like qwen3:1.7b (~1.4 GB) before running your first gated task.
