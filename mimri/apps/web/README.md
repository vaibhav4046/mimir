# Mimri Web UI (`apps/web`)

The live Web App interface is built and served directly from `../../renderer/` (`OverviewView.jsx`, `MimriStackView.jsx`, `ChatView.jsx`, `BoardMeetingView.jsx`, `ComputerPane.jsx`), providing:
- Grok-style Workspace & Chief-of-Staff delegation (`#Growth Team`, `#Product Launch`, `#Executive Updates`, `#All Hands Prep`)
- ACP Remote CLI Subprocess Bridge (`Claude Code`, `Codex`, `OpenCode`, `mimri-cli`)
- Live Sandpack Interactive Full-Stack App Builder & Docker/Vercel export (`MimriStackView.jsx`)
- SWE-bench, OSWorld Computer-Use, and ARC-AGI / MimriDSL Evaluation Runners
- Arize Phoenix OpenInference Trace Waterfall & LiveKit Multi-Speaker Turn Inspector
